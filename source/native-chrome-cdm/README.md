# Smooth Prime stock-Kodi CDM bridge

Owned CDM10 adapter/helper sources for 0.2.66. Genuine regular Chrome remains fixed at user-approved 158.0.8127.89 and is acquired directly from Google. Its runtime and integrity receipt live in Kodi add-on data under native/chrome-cdm/<pin>. Small adapter versions live at adapters/<artifact-identity> and share ../../runtime through runtime_fixture.h. Python chrome_storage.py verifies and stages the immutable pair. Chrome, Widevine signatures, Kodi and ISA binaries are not modified.

Build paths remain workbench-relative: scripts in hd-license-rejection-20261125, sources in chrome-bridge/client-source, incremental targets prime_cdm_proxy and transport_probe. Prior .89 ABI fixtures remain in fixtures/158.0.8127.89. See repository history for the SDK compatibility fixture, third-party revisions and original build setup.
