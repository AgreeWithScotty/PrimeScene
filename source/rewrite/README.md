# Smooth Prime 0.2.36 platform credential storage

Native macOS SecItem and Linux libsecret adapters store credential records outside the profile; profile references contain no payload/key. A Kodi-lifetime memory worker provides session-only fallback where no native store is usable, including Android while no verified Keystore bridge exists. Mutual HMAC-SHA256 challenge authentication on one socket precedes credential delivery; bounded MAC-authenticated JSON frames never use pickle. Migration/deletion journals, current-account transactions, expired-session cleanup and explicit backend diagnostics preserve sign-out guarantees. Native OS adapters have not been exercised on macOS/Linux here; actual socket/filesystem/Windows checks establish only their observed boundaries. Existing UI/catalogue/playback source choices remain.
