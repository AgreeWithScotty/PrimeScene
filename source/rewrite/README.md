# Smooth Prime 0.2.35 security hardening

Original security changes protect saved Windows credentials with current-user DPAPI, restrict private files on POSIX, harden the loopback media capability/server, pin relay HTTPS to public addresses, block cross-origin body/credential forwarding, bound media XML, centrally redact secrets and bound diagnostics. SECURITY.md documents the platform and repository trust limits. Existing UI/catalog/source choices are preserved. Actual local Windows cryptography, filesystem, loopback HTTP rejection and public TLS checks establish only those boundaries; no simulated Amazon/Kodi success claims are made.
