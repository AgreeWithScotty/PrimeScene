# Smooth Prime 0.2.62 accumulated fixes

This installer contains all accumulated changes after 0.2.61: Watchlist/My Stuff
pagination with explicit partial-result retention, focused TV season preparation
and shared metadata reads, clear playback-location refusals and terminal results,
uniform content-title sizes and original-quality Amazon artwork throughout.

Seventeen existing Python modules and the native title XML changed. Version,
changelog and README metadata identify 0.2.62. Actual provider captures, generated
title images and six real public artwork downloads were checked. Every installer
byte matches the frozen reviewed runtime. No provider or Kodi was mocked.

Native Kodi appearance, season-click latency and new authenticated Watchlist
retrieval have not been observed. The US-account/EU-VPN location refusal does not
diagnose the separate EU user's account. Image sources can themselves be small;
the policy requests their original quality rather than inventing extra detail.

Main-branch installer update only. Detailed validation is in change-0.2.62.json.
